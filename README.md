🚀 Next.js Blog-Service
Dieses Projekt ist ein minimalistischer Blog-Service, der mit Next.js 14 (App Router) entwickelt wurde und eine saubere, klassenbasierte Architektur zur Verwaltung der API-Kommunikation verwendet.

* Technologien
* Next.js
* Axios
* TypeScript
* dotenv

# Repository klonen
```Bash
git clone https://github.com/kestenbaum/next-posts.git
cd next-posts
```

# Install
```Bash
npm install
```

# Starten 
```Bash
npm run dev
```
